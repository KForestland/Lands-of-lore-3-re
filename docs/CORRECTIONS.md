## Caught in review before publication

**Reading the program wrongly.**

- 2026-11-20: level save selector 38 was described as 90 arms that each store a vtable. The 90 slots hold 86 distinct arms, and slot 89 is the shared tail, which stores none (merged as `1d20dbc`).
- 2026-11-20: two push addresses in the light-map member scan were wrong (`0x498D60`, `0x499C50`; merged as `1d20dbc`).
- 2026-11-19: the first portal table treated every row whose guard passes as running. The region and object walkers run the first matching row and return (`0x4AC2E9` → `0x4F05D0`, `0x4A826D`), so later rows carry the negation of earlier guards and three rows are else-branches (merged as `a16a68a`).
- 2026-11-19: item handler arguments were given out of call order, a request was called the instance, and one handler was said to write an object field that it does not write (merged as `2636d18`).
- 2026-11-19: the spell-frame table offset was wrong; it is a count at `GLOBAL.WSX+0x16C973` then frames at +0x16C977 (merged as `4115a05`).
- 2026-11-19: the SMD slice phase was said to start at 0.5; the float at `0x54076C` is 0.0 (merged as `03d09b8`).
- 2026-11-19: the MAP loader was said to have 22 seeks; a nested 23rd seek at `0x4EFE96` was missing (merged as `f766cbf`).

**Corrections that were themselves wrong, not taken.**

- 2026-11-20: two writers proposed changing the Numbers page to say the loop at `0x4F0E60` reads +0x4A and writes +0x4B of the 139-byte creature row. The loop pointer is the row plus 0x37 (`lea esi,[edx+0x37]` at `0x4F0D74`), so the bytes are +0x81 and +0x82 as the page says. The page was not changed.
- 2026-11-20: a rating-page rewrite that dropped "not counted as read" and the reviewed PHT wording was not taken (merge `9610b43`).
- 2026-11-20: an offset offered as new (the entry address at `LOL3.DAT+0xF0`) was already documented and checked, and had been put on unrelated pages; not taken.

**Counts and labels.**

- 2026-11-20: the MAP writer counted 13,330 bytes as typed fields although the program only clears them or never reads them. A typed field now needs a native read at that width; the count went from 2.3% through 74.5% to 81.8% of map bytes as reads were found (merged as `3a4882a`, `35d4115`).
- 2026-11-20: the +0xC0 tails (606,420 bytes) were said to be carried "with seek evidence"; the loader only skips them, so they stay listed as copied (merged as `35d4115`).
- 2026-11-20: placement rows were said to be read as "the disk row"; each of five loaders reads them into a stack buffer before the constructor (merged as `35d4115`).
- 2026-11-20: two round-trip paragraphs labelled facts proved on other pages as new proofs; they became plain linked sentences (merged as `9610b43`).
- 2026-11-19: Q8 was raised to "Mostly answered"; the evidence refutes the old labels but does not explain them, so it stayed "Partly answered" (merged as `c4c9e92`).
- 2026-11-19: predicted save differences were labelled as proved before any save pair showed them (merged as `03d09b8`).
- 2026-11-19: handler counts were out of date in the README and the Q12 rows across several batches (merged as `e3c3d63`, `2636d18`).

**Hygiene.**

- 2026-11-19: a commit the reviewer prepared from a writer's work carried conflict markers; it was amended before it was posted or pushed, and the release guard now reports them (`bdc0f01`).
- 2026-11-19: a commit subject named an internal lane (as in the other two repositories); the lead held it, it was reworded before the push, and the guard now checks commit messages (`c9bef4a`).
