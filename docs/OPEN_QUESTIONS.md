# Open questions

Numbered so pages and the [STATUS table](STATUS.md) can point to them. Each says what is known and what would settle it.

For debugger procedures that use the original game, see [Needs a running game](NEEDS_A_RUNNING_GAME.md).

## At a glance

One line per question: its state and what would settle what is left. Device colour output (Q6, Q9), save pairs (Q13) and some trigger conditions (Q12) need a running original game; the other next steps need only the original files.

## Questions

| # | Question | Where |
|---|---|---|
| Q1 | `cdcache.wsx`: two different files carry this name. Only the one in `DAT/` (3,264,114 bytes) ships; the one in the game folder (104,896,114 bytes) is written by the game when it runs. They both have a 9-entry header covering 52,663,793 bytes. The game-folder copy holds the 854 texture records, 420 of them after the area the header covers ([formats/textures.md](formats/textures.md)). Native expansion and the secondary allocator directory are confirmed, including eight occupied spans. Open: the origin of the shipped compact `DAT/` copy and row byte +0x17 | [Native WSX reader](lol3-wsx-reader.md) |
| Q2 | **Answered.** Native rotate-right name hash, case normalization and 76 exact name/key joins. Names of other entries remain unconfirmed | [Native WSX reader](lol3-wsx-reader.md#resource-name-key) |
| Q3 | LMF light maps: native directory, grouped LZO1X and decoded member sizes confirmed. Native consumer reads +8 and begins samples at +0x2C. Remaining disk flag and header meanings are open | [Native LMF reader](lol3-lmf-reader.md) |
| Q4 | **Mostly answered.** Waypoints, paths and surfaces are read natively. Section-1's eight bytes each have a reader or a writer. The 26-byte slots and 31-byte slots are printable labels outside those reads; waypoint byte +6 is tabulated and travels in the saved row; the 1,784 bytes before field 16 are 223 groups of four u16 with no seek. Open: a reader of byte +6, of either label span, and of field 2 + 56×field 21 | [Native MAP reader](lol3-map-odf-readers.md) |
| Q5 | ODF readers, table strides and the fields of the type-tagged field-3 definitions mapped (most tags read as creatures or actors, e.g. RHOUND, ORC, SPIDER; a few are object ids, so the creature reading is UNCONFIRMED). Four AI resource paths resolve from the tags. Other per-row meanings remain open | [Native ODF reader](lol3-map-odf-readers.md) |
| Q6 | **Answered for supported cache records and one device.** In the game-written cache, 10,669 records decode to PNG. Another 4,429 resolve to SMD frames in the shipped SLICECD1–4. All 1,979,019 runs frame exactly, and the native row projection and depth test are mapped. The Wine Direct3D selector and both surfaces of a traced texture copy used `7C00/03E0/001F/8000`. SMD rasterization, the last 20 copy paths and final display colour still need witness comparisons. | [Texture checks](lol3-texture-bake.md#slice-directory-and-run-decoder), [live device selection](lol3-texture-bake.md#live-direct3d-texture-format), [running-game test](NEEDS_A_RUNNING_GAME.md#q6-which-packed-format-does-the-live-device-select) |
| Q7 | **Mostly answered:** all 18 original `.TE_` banks expand through LZO1X. The former `+1` witness is inside a compressed block. The editor-name branch `0x43FFE4–0x44000D` converges on the same reader; only a differently framed standalone file remains unwitnessed | [Texture formats](formats/textures.md) |
| Q8 | What the QWOD0 and SWOD4 byte-pattern labels mean in the game. MAP and ODF entries mapped. The old labels require recoverable file positions and a native consumer | [lol3-semantic-phase.md](lol3-semantic-phase.md) |
| Q9 | Movies. **Partly answered:** the 19 `MOVIES1..4` entries are named VQA files read by `0x50DF70`; frame index and sound chunks checked. LINF/CINF tables, LCW payloads and 4×4 tile pointers confirmed ([vqa](formats/vqa.md)). The [live Direct3D witness](formats/vqa.md#live-introduction-opener) converts original frame 16 word `0x0421` to RGB565 `0x0841`, then copies it through `0x516A40`. Full-frame host comparison and other renderers remain open | [formats/vqa.md](formats/vqa.md), [running-game test](NEEDS_A_RUNNING_GAME.md#q9-what-colours-does-the-vqa-frame-callback-present) |
| Q10 | Music and sound. **Mostly answered:** the 6,696 level sounds in the 18 sidecar archives are RIFF WAVE, format 17 (IMA ADPCM) ([level sheets](levels/README.md)). The 38 `MUSIC1..4` tracks and their Miles stream path are documented ([formats/audio.md](formats/audio.md)). The stem initializer was traced and 37 entries join. One name remains open | [formats/audio.md](formats/audio.md) |
| Q11 | Scripts. **Mostly answered:** all original MAP scripts frame exactly with the 39 native opcode lengths; the dispatch tables, event pools, predicates, timers and the 480 Hz host frame clock are mapped ([events](lol3-script-events.md)). The selector byte of an object command is the object type, and opcodes 0x01, 0x03 and 0x0D are resolved per class: movers go to a percentage of their travel, players and creatures receive items, the 33 creature subcommands set behaviour, action, targets, paths and flags, and the other classes ignore the command ([per-class effects](lol3-script-opcodes.md#per-class-effects-of-the-indirect-commands), checked by `lol3_script_framing.py --check`). Opcode 0x0F's 16 stored actions and opcode 0x1C build type-5 effect objects; opcode 0xC4 animates floor or ceiling heights. **UNCONFIRMED:** the on-screen look of those effect classes and of the object at `0x5860F0` that opcode 0x1A drives | [Script opcodes](lol3-script-opcodes.md), [object dispatch](lol3-object-dispatch.md) |
| Q12 | Items, spells, dialogue and combat. **Partly answered:** the 343-row item table, 28 spell definitions, the dialogue and quest tag lookup (2,641 of 2,642 dialogue commands join), the creature hit resolver, item-use dispatch, cast cost and mana debit are traced. Eight regular handlers are mapped, including the [two alternate charge producers](lol3-spell-dispatch.md#producers-of-the-alternate-counters). The first counter debited in a [live cast](lol3-spell-dispatch.md#casts-with-a-null-sink). Open: the second live debit, other handler effects, discount selectors and mitigation mask names | [Items](lol3-item-dispatch.md), [spells](lol3-spell-dispatch.md), [dialogue](lol3-dialogue-dispatch.md), [combat](lol3-combat-dispatch.md), [running-game test](NEEDS_A_RUNNING_GAME.md#q12-which-live-cast-consumes-an-alternate-resource) |

Controlled original saves isolate the player heading and forward coordinate and follow one item reference from the quick slot to the cursor. Pickup from the world and other payload meanings remain open. | [Controlled native saves](lol3-native-saves.md#controlled-saves-with-a-null-sink), [running-game test](NEEDS_A_RUNNING_GAME.md#q13-which-original-save-bytes-follow-one-controlled-action) |
